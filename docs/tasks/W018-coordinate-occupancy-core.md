# W018 — 实施工艺坐标与离散占用状态内核

## 任务要求（PM）

M1，Stage 2。交付可被后续 Stage 2 组装代码调用的产品组件。起点是 W017 已集成的 main `504d9b07c08160d46a9aaa4fd3346a144ac5db32`，分支 `codex/w018-coordinate-occupancy-core`。当前阶段为内核可执行，产品实现待独立执行 session 交付。[架构 §2.3、§3.4–3.6、§11.3](../architecture.md) · [W017 来源及复算](W017/proposal.md)

**从已有代码接起。** W008 已把认证的 drawn records 按各层图形边缘分格，并保留每个占用片段。本次从同一份精确几何及明确给出的逐层坐标参数出发，在选定坐标系下构建可重建的占用状态。复用已有矩形、单位绑定、来源引用和求交逻辑。W009 的有效区域与原始 drawn 几何分别标记来源。旧组件和消费者继续按原索引工作。同一几何保留一个权威来源，各种索引均能追溯到它。[坐标](../../layauto_v2/state/coordinate.py) · [占用](../../layauto_v2/state/occupancy.py) · [有效区域](../../layauto_v2/state/regions.py)

| 验收 | 正式代码应做到的事 |
| --- | --- |
| A1 坐标 | 定义逐层坐标参数和有限范围。给定方向、原点、节距和偏移，精确换算物理点、轨道号与格边。用现有 FIN 配置和 GDS 复算 18 条中心线，检查两轨之间、负坐标、非零偏移和半开边界。 |
| A2 占用 | 给定已校验的 layout、坐标和层策略，构建不可变的离散占用结果。可按层和格取全部片段，也可从原图形找回全部覆盖。每片携带确切边界、单位和 record 来源；有效片段另保留 region/piece 及 CUT 贡献者。支持同格多占据及不同来源的相同矩形。 |
| A3 端到端 | 正式测试从真实 fixture 的认证几何进入产品构建函数；S2 四片无重叠地拼回 32 DBU²，S3 两块 LI 各 36 nm²，间隔 2 nm，在指定示例格中仍分别可追溯。另测换轴或相位后覆盖变化、原几何稳定。20×10 和 32×16 只作各自样张的显式参数。 |
| A4 边界和成本 | 缺轴保留原几何。测试错单位/异源有效区域、越界和巨幅稀疏网格。先估算命中的总片数，只为实际占用分配；用显式测试预算检验累计超限时结果完整性。记录代表路径的耗时、峰值与片数。 |
| A5 工程交付 | 在 `layauto_v2/` 和正式 tests 实施，给一条从真实文件构建占用并检索来源的可复现命令。未参与实现者检查接口依赖、精确性、覆盖重建、兼容性和资源。按[验证复用规则](../collaboration/rules.md#verification-reuse)开发期跑新增/受影响项，冻结交付时执行双版本全量、typing、构建、干净安装及源码外 smoke。 |

**实施边界。** 先用内存中的显式参数连接已验证几何与产品构建函数，记录参数来源及适用范围。坐标数学和局部占用构建仅依赖所需几何、单位及层策略，函数签名不要求 body、CDL 网络或父级信息。可通过已有 W008 输入链取得样本几何做组合验证。接入 W016 无 tapcell 公开入口、正式用户文件格式、公开查询 API、产品默认片数和 Stage 2 baseline 发布分别保留到对应接入决定。W017 的 D1–D3 仍为对外提案。

## 启动指令
