## Internal base partition and proof

Version `drawn-layer-edges/1`: for each layer declaring `exact_fragment_rectangles`, sort the unique x and y bounds of that layer's drawn records. Consecutive bounds define finite cells; only occupied cells produce fragments. Empty projected layers have no cells. C1/C2 with `none` stay in layout only. No pitch, legal track, default bucket, FIN-derived axes or electrical-connects-derived coordinate exists.

Cells use half-open intervals `[x_i,x_(i+1)) × [y_j,y_(j+1))`; min edges belong, max edges do not. Rectangle coverage is represented under the same half-open convention; its closure recovers the original closed polygon boundary. Point-to-index uses exact comparison/bisection and rejects points outside that finite domain. Index-to-bounds returns exact canonical integer DBU, with physical nm conversion through the same unit binding. Internal gaps are valid empty cells, not asserted legal locations.

Project each record into every positive-area rectangle/cell intersection. Because its own bounds occur in the ordered axes, the consecutive disjoint intervals tile exactly that rectangle: their Cartesian products are pairwise interior-disjoint and union to it. For hand example A=[-2,0,4,4], B=[1,1,5,3], x=(-2,1,4,5), y=(0,1,3,4): A occupies six cells, B two, with two occupants in cell (1,1). Sum A areas=24 and B=8. Equal duplicate records add occupants, never overwrite. A named test-only coarse partition exercises two disjoint fragments in one cell; it is never the runtime model.

`state.coordinate.BasePartition` owns only math and immutable layout input/reference, no occupancy. Its constructor regenerates/validates axes from its immutable layout for the supported algorithm; model identity binds version, boundary convention, layout identity and exact axes. `state.occupancy.BaseOccupancy` refers to that partition (whose layout is the sole immutable drawn owner) and holds a canonical tuple of typed fragments. Its constructor regenerates expected projection and rejects omitted/foreign/duplicate/wrong-cell/wrong-rect fragments; read-only cell/record lookup is derived. Result exposes layout/partition via this single immutable chain rather than independent driftable copies. VIA/CONTACT/CUT retain only their own drawn layer occupancy; no topology, terminal split or annotation.
